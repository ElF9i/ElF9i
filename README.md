My passion lies at the intersection of **IoT, embedded electronics, software development and intelligent systems**.

## 🧩 Featured Projects

### 01 — MedBox | Smart Connected Medicine Box

An IoT-based project designed around intelligent monitoring and wireless communication.

- Sensor data acquisition.
- LoRa communication using Heltec boards.
- MQTT-based data transmission.
- Monitoring and visualization using Node-RED.

**Technologies:** `Heltec WiFi LoRa 32 V3` `DHT11` `LoRa` `MQTT` `Node-RED`

### 02 — Data Center IoT Monitoring Platform

A virtualized IoT monitoring architecture developed during my internship at CIMS (Ministry of Health, Tunisia).

The project simulates environmental measurements and provides centralized monitoring through dashboards.

**Architecture:**

```text
Wokwi ESP32 Simulator
        |
        v
Node.js / Express API
        |
        v
MQTT / Data Processing
        |
        v
Telegraf / InfluxDB
        |
        v
Grafana Dashboard
```

**Technologies:** `ESP32` `Wokwi` `Node.js` `MQTT` `Ubuntu` `InfluxDB 2` `Grafana` `Telegraf` `VirtualBox`

### 03 — Wireless Environmental Monitoring Station

An embedded monitoring project using a Heltec development board and a DHT11 sensor.

- Temperature and humidity acquisition.
- OLED display integration.
- Wireless connectivity.
- Data transmission to ThingSpeak using HTTPS.

**Technologies:** `Heltec WiFi LoRa 32 V3` `DHT11` `Arduino IDE` `C++` `Wi-Fi` `HTTPS` `ThingSpeak`

### 04 — Raspberry Pi IoT Monitoring

Experimentation with a Raspberry Pi 4 as an IoT data collection and monitoring platform.

- Linux-based environment.
- Sensor integration and data acquisition.
- InfluxDB installation and configuration.
- Grafana dashboard experimentation.

**Technologies:** `Raspberry Pi 4` `Debian` `Python` `InfluxDB 2` `Grafana` `Linux`

### 05 — STM32 Embedded Applications

Practical embedded systems development using STM32 microcontrollers.

- GPIO configuration and digital I/O.
- ADC acquisition and sensor interfacing.
- UART serial communication.
- LCD I2C integration.
- LED, buzzer and button control.

**Technologies:** `STM32F401RE` `STM32L476RG` `STM32CubeIDE` `C` `UART` `ADC` `GPIO` `I2C`
